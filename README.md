# Open City — Endless Roads

A lightweight, single-file top-down 2D driving and exploration game built with vanilla HTML, CSS, and Canvas JavaScript.

## Features

- **Infinite Procedural World:** Seamlessly streaming neighborhoods featuring downtown towers, suburban streets, parks, canals, six-lane expressways, four distinct old-town styles, off-road forest/badland trails, and regional-to-international airports.
- **Four Game Modes:**
  - **Free Roam:** Relaxed, open-ended exploration at your own pace.
  - **Police Chase:** Outrun and take down up to five coordinated pursuit units.
  - **Bus Transit:** Pick up and drop off passengers across 2–6 stop routes with no time limits.
  - **Freight Truck:** Haul cargo from local depots to distant shops on regional and cross-country routes.
- **Garage & Progression:** Every kilometre driven and job completed earns spendable distance (`km`) saved automatically in `localStorage`. Upgrade engine, turbo, cooling, and brakes across all vehicles, or customize *The Runabout* with paints, liveries, wheels, underglow lights, and body kits.
- **Dynamic Traffic & Pickups:** Lane-following AI traffic with junction right-of-way logic, plus temporary road pickups (*Speed Boost*, *Ghost Drive*, and *Infinite Nitro*).
- **Interactive Atlas & Minimap:** Pan, zoom, and pin nearby airports, old towns, highways, or off-road trails.

## Controls

| Action | Key |
| :--- | :--- |
| Accelerate | `W` / `↑` |
| Brake / Reverse | `S` / `↓` |
| Steer | `A` `D` / `←` `→` |
| Handbrake / Drift | `Space` |
| Turbo Boost *(when unlocked)* | `Shift` + Accelerate |
| Recover to Road | `R` |
| Accept Job | `E` |
| Open Garage | `G` |
| Open City Map | `M` |
| Cycle / Open Game Modes | `C` / `V` |
| Pause | `Esc` / `P` |

*Touch controls are automatically enabled on touch-capable devices.*

## Getting Started

No build step, dependencies, or server required. Simply open `open-city-infinite (1).html` (or rename to `index.html`) directly in any modern web browser.
